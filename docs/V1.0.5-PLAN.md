## 0. 上下文

### 0.1 用户原始需求（2026-08-20）
> "小人初步就是像是厕所标识上的那种小人就行，不要各种细节，颜色待定，动作就是走路双脚、手、点头啥的。然后这个先不进行，先和之前的待做合并一下"

### 0.2 需求解读
- **风格**：厕所标识剪影风格（简洁、像素、对称剪影）
- **细节度**：不需要精致，剪影即可
- **颜色**：占位色（Tailwind 5 色 + CSS var），后期调
- **动作**：走路（双脚交替）、手部动作、点头
- **优先级**：**最后做**（用户原话"动画升级最后"）
- **前置依赖**：v1.0.4 Framer Motion 微动效基础设施

### 0.3 渐进升级策略
1. v1.0.4: 现有圆形头像 + 微动效（点头 / 敲锤 / 气泡）
2. v1.0.5: **替换为剪影小人 SVG**（带走路 / 点头 / 举手）
3. v1.0.x+: 后续可升级为 Lottie 立绘（设计师产出时再做）

**v1.0.5 不引入 Lottie/Rive**，因为：
- 用户明确"不需要细节"
- 设计师产出成本高
- 剪影 SVG + CSS 动画已足够满足需求

### 1.2 SVG 设计原则（厕所标识风格）

**5 角色 SVG 设计**：
- 风格：纯色剪影（无细节、无渐变）
- 尺寸：64x64 或 96x96 viewBox
- 对称：左右对称剪影（无头发、衣服细节）
- 角色特征：
  - **控方律师**：圆形头 + 站立姿势 + 举手指控（指尖向上）
  - **辩方律师**：圆形头 + 站立姿势 + 双手打开辩护
  - **调查员**：圆形头 + 蹲下 + 拿放大镜
  - **法官**：圆形头 + 坐姿 + 拿法槌
  - **书记员**：圆形头 + 低头打字

**SVG 模板示例（控方律师）**：
```svg
<svg viewBox="0 0 64 64" xmlns="http://www.w3.org/2000/svg">
  <!-- 头 -->
  <circle cx="32" cy="14" r="8" fill="currentColor" />
  <!-- 身体 -->
  <rect x="22" y="22" width="20" height="22" rx="2" fill="currentColor" />
  <!-- 左脚 (走路动画分离) -->
  <rect x="24" y="44" width="6" height="16" rx="1" class="silhouette-leg-left" fill="currentColor" />
  <!-- 右脚 (走路动画分离) -->
  <rect x="34" y="44" width="6" height="16" rx="1" class="silhouette-leg-right" fill="currentColor" />
  <!-- 手指控方 -->
  <rect x="14" y="20" width="3" height="14" rx="1" class="silhouette-arm-pointing" fill="currentColor" />
</svg>
```

### 1.4 CSS Keyframes（走路 / 点头 / 举手）

```css
/* 走路 — 双脚交替 (0.8s 循环) */
@keyframes silhouette-walk {
  0%   { transform: translateY(0) rotate(0deg); }
  25%  { transform: translateY(-2px) rotate(5deg); }    /* 左脚抬起 */
  50%  { transform: translateY(0) rotate(0deg); }
  75%  { transform: translateY(-2px) rotate(-5deg); }   /* 右脚抬起 */
  100% { transform: translateY(0) rotate(0deg); }
}

.silhouette-leg-left {
  animation: silhouette-walk 0.8s ease-in-out infinite;
  transform-origin: center top;
}
.silhouette-leg-right {
  animation: silhouette-walk 0.8s ease-in-out infinite reverse;
  transform-origin: center top;
}

/* 点头 — 身体微微点头 (1.2s 循环) */
@keyframes silhouette-nod {
  0%, 100% { transform: rotate(0deg); }
  50%      { transform: rotate(8deg); }
}

.silhouette-nod {
  animation: silhouette-nod 1.2s ease-in-out infinite;
  transform-origin: center bottom;
}

/* 举手指控 — 律师专属 (2s 循环 + 抬升) */
@keyframes silhouette-point {
  0%, 100% { transform: rotate(0deg) translateY(0); }
  50%      { transform: rotate(-15deg) translateY(-3px); }
}

.silhouette-arm-pointing {
  animation: silhouette-point 2s ease-in-out infinite;
  transform-origin: center bottom;
}

/* 调查员放大镜 — 旋转 */
@keyframes silhouette-magnify {
  0%, 100% { transform: rotate(0deg); }
  50%      { transform: rotate(20deg); }
}

.silhouette-magnifier {
  animation: silhouette-magnify 1.5s ease-in-out infinite;
  transform-origin: center center;
}

/* 法官敲锤 — 关键帧 */
@keyframes silhouette-gavel {
  0%, 100% { transform: rotate(0deg) translateY(0); }
  30%      { transform: rotate(-10deg) translateY(-4px); }  /* 举锤 */
  60%      { transform: rotate(10deg) translateY(0); }       /* 落锤 */
}

.silhouette-gavel {
  animation: silhouette-gavel 0.4s ease-in-out infinite;
  transform-origin: center bottom;
}
```

## 5. 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| SVG 在小尺寸看不清细节 | 视觉质量差 | viewBox 96x96 + scale 适配 |
| CSS keyframes 在低性能设备卡顿 | 庭审卡顿 | `will-change: transform` 启用 GPU + 减少 reflow |
| 5 个角色 SVG 不一致 | 视觉割裂 | 统一 viewBox + 统一头部比例 |
| 颜色后期调整涉及所有 SVG | 改色困难 | CSS var 解耦（fill="currentColor"） |
| 走路动画遮挡文字气泡 | UX 差 | 用 `motion.div` 调 y 偏移 ≤ 3px |

## 8. 不做什么（明确边界）

- ❌ **不引入 Lottie / Rive** —— 用户明确"不需要细节"
- ❌ **不做设计师立绘** —— 厕所标识剪影够用
- ❌ **不做 3D / R3F** —— 用户明确"2.5D"是 2D 立绘 + 透视感
- ❌ **不做 Live2D 风格的复杂互动** —— 剪影 + CSS keyframes 够
- ❌ **不做 per-role 独立动画配置** —— 5 角色共用 CSS keyframes（差异化通过 className）
